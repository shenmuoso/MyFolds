# 文件管理器设计稿

Mode: Operate。交付设计提案及示例数据交互原型，非原生产品实现。

## Direction contract

THESIS: 路径常驻、操作结果可预判、选中即预览。默认单浏览区加检查器，整理时切换双栏，避免双栏挤压媒体预览。

OWN-WORLD: 摄影接触印样的紧凑对齐、冷白底、墨蓝文字、浅蓝选择；macOS 系统字体；灰蓝侧栏承载位置。世界只影响色彩、字形、密度和选中状态，不改写原生控件的语义。

STORY: 用户看到完整路径，选中文件并预览，剪切时进入等待移动状态，到目标位置粘贴后得到明确结果；所有数据均为演示。

FIRST VIEWPORT: 1440×1000 桌面设计页；上方简短提案工具栏、中央完整应用窗口；190px 位置侧栏、弹性文件区、300px 预览；路径与文件动作各占一行；窗口下方是场景导航。默认选中山景照片并展示元信息。签名交互为剪切后底部出现含来源、目标与取消按钮的待移动栏；媒体放大 160ms 淡入，Reduce Motion 下即时切换。

FORM: grounded candidate 6，摄影接触印样；seed:95aa0ee79c5e9e42。本轮先给用户完整可审阅的设计提案，视觉取向是建议，尚非用户确认的产品品牌。候选系统包含公共图书目录、轨道站点导视、展览作品标签、地图集、书籍索引、摄影接触印样、邮政分拣标签。目录可扫描性与原生控件约束优先；目录墙候选仅支持媒体聚焦，不能覆盖完整文件管理，因此不采用其导航形式。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 范围

- 日常浏览、地址补全、单/双栏、复制剪切粘贴、同名冲突、图片/视频预览、打开方式作用域、压缩包只读浏览与提取。
- 空、加载、无权访问、无搜索结果、取消、失败均进入设计说明与可演示入口。
- 原型不读写真实文件，不改变系统文件关联；应用名和格式支持均是方案。
- 默认假设：中文、桌面键盘鼠标、本地文件优先；最低系统版本和发行方式待定。
