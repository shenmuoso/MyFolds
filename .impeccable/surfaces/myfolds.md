# MyFolds · Apple 官方参考后的结构重制
Mode: Operate。交付仍是产品方案与 HTML 交互设计预览。

## Direction contract
THESIS: 日常整理应像一个原生 macOS 文件窗口，路径可直接操作，文件内容始终清楚。
OWN-WORLD: 用户否定 v0.3；以实际浏览的 Apple macOS 27 Mail/Safari 参考校准。近黑 SF Symbols、系统字体、少量玻璃功能组、贯穿边缘的磨砂侧栏、32% 填充的半透明雾灰内容底（浅 #F1F0ED，深 #232320）加 28px 背景模糊。表头透明，无独立材质层；滚动文件行在表头下方裁切。展示背景默认 36 秒 RGB 循环，可暂停、调通道及切回暖壁纸；这些是预览页控制。
STORY: 进入目录后立刻浏览文件；剪切与粘贴在工具栏，完整路径在底部，媒体预览按需开启。单标签不出现额外标签行。
FIRST VIEWPORT: 约 194px 通高侧栏，64px 单层工具栏，默认列表且没有空预览栏；38px 底栏容纳可编辑完整路径和项目状态。真实多标签时出现 34px 标签行。玻璃组用于关联操作而非每个图标单独套壳。
FORM: seed: none (pinned)。用户要求“macos原生的风格，简洁、高级、磨砂质感，且支持macOS 27 的玻璃”，并指定“可以去apple的macos宣传页看看”。保留五项已确认需求，重制被拒绝的窗口结构。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 依据与边界
Apple 官方当前 macOS 页面：https://www.apple.com/os/macos/ 。原生实图位于 outputs/myfolds-reference/，用户实际否定截图位于 work/myfolds-v4/user-rejected-v3.png。官方宣传裁图仅作为视觉关系参考，不能直接换算为 pt。HTML 近似材质不等同于系统 Liquid Glass。

表头修正独立限定范围复核：ship，无必修项；核查范围为共享材质、裁切边界与已采样状态，不覆盖原生系统性能。


## Preferences refinement
用户指出偏好设置缺少 macOS 原生细节，要求参考系统设置。本轮仅替换旧的通用设置弹窗，保留主文件窗口、32% 内容材质、透明表头与 RGB 预览。直接查看本机系统设置的外观和通用页面，提取独立窗口、侧栏导航、缩略外观选项、左标签右控件、分组内轻分隔的关系。裁去账户信息的原生截图位于 outputs/myfolds-design/reference/Native-Settings-*.png。
THESIS: 设置应是一扇熟悉、安静、即时生效的独立窗口。
FORM: Operate；760×552px 的网页预览窗口，190px 侧栏，52px 标题栏；外观、打开方式、快捷键三类。保留系统字体与 SF Symbols，磨砂侧栏、稳固但透色的内容面、低反差分组。不复制系统账户、网络等无关分类。
BEHAVIOR: modeless，不调暗主窗口；浅/深/自动、密度、辅助功能、三类默认应用使用真实演示状态。设置内按键不触发背后的文件操作；Escape/⌘W 关闭，⌘, 打开。原型不修改系统偏好，值仅保留在本次演示中。
FINISH: 独立复核、交互检查、来源元数据与文档同步后交付。原生参考只支持视觉关系，不构成 macOS 27 API 实现证明。

偏好设置独立完整复核：ship，五项契约齐全，无必修项。13 张有效设置截图与记录的浏览器交互作为证据；原生参考仅用于视觉关系。文档令牌按最终源码同步。

## Settings material correction — user feedback overrides prior verdict
用户指出 v0.6 设置与主窗口不是同一风格，缺少玻璃和磨砂透明质感。上一轮对布局/交互的通过不能作为材质通过依据。本次只重建设置材质堆叠：外壳透明且仅一层 32px / 1.25 背景模糊；设置叠在已经磨砂的主窗口上，因此侧栏/内容只施加薄层色调，不再堆叠 65% / 78% 底色和 36% 白色分组。浅色填充 6% / 14% / 6%，深色 12% / 20% / 2.5%。窗口共用主窗口投影、18px 圆角和细亮边；导航改为同样的中性透色选中态与单色 SF Symbols。布局、内容、真实控件和键盘行为保留。必须在相同红/绿/蓝背景下对照合成后的主窗口与设置；不能以 CSS alpha 或检查通过替代视觉判断。

材质重建后的独立完整复审：disposition: ship，无 material_fixes。16 张设置截图及 6 张同色 RGB 原图有效，实际透色、白色分组消退、图片背景可读性、深色、减少透明度和窄窗均已核对；370px 说明与固定页脚没有重叠。DESIGN.md 与 sidecar 同步，117 个交付位图的来源记录无缺失。此结论限定 HTML 原型的本轮材料修正，不能代替用户的审美判断或原生 Liquid Glass 验证。


## Native 0.1.1 material repair — 2026-11-21

0.1.0 的减少透明度回退错误：隐藏唯一磨砂层后，依赖的 NSWindow 背景可被 SwiftUI 清空，用户看到全透。0.1.1 由 MaterialContentController / MaterialView 在 AppKit 树中共同管理磨砂、独立不透明填充、SwiftUI 内容及子控制器；保留窗口所有权。默认使用 NSVisualEffectView HUD / behindWindow / active / alpha=1，原确认稿的布局和前景轻叠色保持。减少透明度实底复用 reduced-window #e7e6e2 与 dark-reduced-window #353530。

用户在实际产品主窗与设置的 RGB/文字背板上确认颜色透出且背景文字模糊，要求增强后进一步确认“现在合适，保留这个效果”。此确认优先于不能保留后方合成的单窗口截图。3项材质回归覆盖旧版alpha=0缺陷、浅深色、真实Preferences更新、双窗口、resize及重开；22项核心测试通过。此修正与确认不代表首版功能清单全部完成。

## 原生 0.1.3 导航、动效与文档 — 2026-11-21

以下为当前原生版本规则，取代前文 HTML 原型及 0.1.2 中关于底部地址栏、单标签隐藏、无路径建议和无内置编辑器的旧规则。保留已确认的 HUD / behindWindow / active / alpha=1 磨砂容器与不透明回退色，不为动效修改玻璃参数。

标签行始终可见，选中项使用 18% 系统强调色、半粗体和明确关闭按钮；新增入口固定在行末。标签宽 190 pt，间距 4 pt，高 30 pt。选中底块在标签间连续移动，文件内容以淡入淡出切换；新建、关闭、分栏和检查器的布局变化使用克制过渡。反馈 140 ms、内容 200 ms、布局 280 ms；减少动态效果合并系统设置与应用偏好，移除空间位移，保留 100 ms 状态反馈。玻璃模糊不参与动画。

每个窗格顶部都有独立地址栏与补全状态，当前窗格使用轻强调色和底部文字标记，不使用单选组切换窗格。整栏点击或 ⌘L 进入编辑；仅输入后展示下一级文件/目录前缀匹配，↑↓ 选择、Tab 补全、Return 前往。文件路径定位到父目录并选中文件。

文件读取、筛选排序、压缩目录投影、路径补全、媒体解码、文本读写与 DMG 子进程在数据层执行，主线程接收状态和快照。旧请求取消及请求标识防止过期结果覆盖新路径。加载、错误、空目录、筛选和路径定位状态可辨认。

内置文本/Markdown 编辑、图片、视频与 PDF 窗口沿用主窗口材质。编辑器用原生文本系统，支持撤销、保存、另存为、关闭保护和外部修改冲突检测。Markdown 支持常用块级结构及本地图片，不执行 HTML/JavaScript。显式外部打开规则优先，用户也可单独将某类或后缀指定为内置查看器。

首次打开集中提供文件访问说明、完整磁盘访问的系统入口和目录授权；应用不能自行授予 macOS 完整磁盘访问。授权目录通过安全范围书签记忆。


## 原生 0.1.4 双栏与快速访问 — 2026-11-21

本节取代 0.1.3 的浅强调色标签/路径规则，并按用户后续要求统一强调色。选中标签、侧栏、文件列表和图标文件名使用同一强调色；未选标签保持浅灰 RGB(0.79, 0.80, 0.82)，文字为 RGB(0.20, 0.21, 0.23)。路径栏独立保持深灰 RGB(0.27, 0.28, 0.30) 与白字。标签仍为 190×30 pt、4 pt 间距、8 pt 圆角；选中背景保留移动过渡，减少动态效果时停止位移。路径输入文字和插入光标均为白色，补全浮层保留系统材质与标准前景。

“偏好设置 → 外观”提供跟随系统及蓝、紫、粉、红、橙、黄、绿、石墨色，修改即时生效并持久保存。默认跟随系统选中背景色；深色系保持白字，黄、橙、绿使用深色字，浅深两种外观下选中文字对比均不低于 4.5:1。AppKit 列表和 SwiftUI 视图共用 SelectionPalette，修改颜色不会重载列表或清空选择。设置导航、外观缩略图和拖入快速访问的反馈同步使用该颜色。

双栏分别拥有标签行和固定新增按钮。快捷键作用于当前窗格，两侧选中标签同时使用强调色，底部“当前窗格”文字和路径中的 ⌘L 提示区分键盘目标；不使用 radio group。左右标签目录和选中序号持久化，收起右栏保留其标签。

快速访问位于固定个人位置与挂载卷之间，始终显示。空状态说明可拖入文件/文件夹，拖入时以轻强调色显示接收区域。文件与文件夹使用原生 SF Symbols，右键可移除引用。文件菜单“添加到快速访问”、空白菜单“添加当前位置到快速访问”都捕获调用时的目标；添加不进行复制或移动。

偏好设置下方显示黄色/琥珀色“打开磁盘权限”，浅色使用深琥珀前景和黄色轻底，深色用金黄色前景。检查失败或未知时保持可见，应用回到前台复查，首次引导完成不表示系统授权。废纸篓走当前窗格导航，受限时在内容区提供系统权限入口，正常列表复用现有内容材质。空目录菜单覆盖完整文件区域。

MaterialView、OpaqueMaterialFill、MaterialContentController、WindowMaterial 及其 HUD / behindWindow / active / alpha=1 参数保持逐字一致。单窗口截图仍不作为桌面合成效果的重新验收依据。

## 原生 0.1.6 侧栏分类与浅强调色 — 2026-11-21

本节取代 0.1.5 的浅灰标签/路径及此前黄色磁盘权限提示规则。未选标签和地址栏共用当前强调色的轻叠色，浅色 16%、深色 24%；使用系统主文字与随外观变化的原生输入文字、占位文字及光标。选中标签保持完整强调色。权限提示采用同一轻底，文字/盾牌为同色系高对比前景；悬停增加 10% 叠色。修改强调色实时同步左右窗格和权限提示。32 pt 高度、8 pt 圆角和已有动效保留。

## 原生 0.1.7 外观、编辑器与图标 — 2026-11-21

保留 0.1.6 的结构、32 pt 标签/地址栏、轻强调色与用户确认的 HUD 磨砂。外观改为单一窗口所有者：自动模式继承系统的 effectiveAppearance，SwiftUI 内容接收对应色彩方案；不再同时施加 preferredColorScheme。原生红绿灯由内容视图持有，布局或主题变化不再从标题栏移动系统按钮。主窗、设置、编辑器共用此机制。HUD / behindWindow / active / alpha=1 与不透明回退 #e7e6e2 / #353530 保持原值。
