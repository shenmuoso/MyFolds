# Design System: MyFolds

## Overview

**Creative North Star: "原生 macOS 文件窗口"**

MyFolds 是已确认的品牌。用户指定 macOS 原生、简洁、高级、磨砂质感，并以 macOS 27 为适配目标。v0.6 延续实际浏览的 Apple macOS 宣传页面所校准的窗口比例、控件分组和侧栏关系：系统字体与近黑 SF Symbols 为主。窗口外的设计预览默认使用动态 RGB 背景，保留暖色壁纸模式；不固定为单蓝色或全暖色，允许用户指定 RGB 色彩来观察材质。

窗口由通高侧栏、单层工具栏、稳定文件内容和底部路径栏构成。玻璃用于关联操作组；默认列表、不预选文件且关闭预览，多个真实标签才显示标签行。内容区使用半透明暖雾灰和背景模糊，吸顶表头保持透明并共享内容区的单层材质，前景文字和图片保持清晰。外围窗口与控件保留玻璃层次。本文提取当前 HTML、style.css 对 components.css、preview-background.css 与 settings.css 的最终级联，以及 app.js、preview-background.js 与 settings.js；RGB 控制仅属于设计预览，不是文件管理产品功能。网页材质、窗口控制与文件数据均为模拟，不表示已实现系统 Liquid Glass、真实文件访问或完成原生验证。

偏好设置参考本机 macOS 系统设置的分组行和外观选择关系，使用独立的非模态窗口，提供外观、打开方式与快捷键三类内容。更改即时生效，仅保留在本次演示的内存中；“自动”跟随系统外观，打开方式只改变 MyFolds 内的演示选择。设置窗口复用主窗口的玻璃模糊、细亮边与投影，侧栏与内容面用薄叠色补偿背后的既有磨砂；内容独立滚动，主文件窗口仍可操作。

**Key Characteristics:**
- 194 px 通高磨砂侧栏、64 px 单层工具栏、38 px 底部完整路径与状态。
- 默认列表与按需预览；多个真实标签才显示 34 px 标签行。
- 近黑单色符号、少量玻璃功能组、半透明雾灰内容面与共享材质的透明表头；窗口外提供 RGB 材质预览。
- 独立滚动、窄窗侧栏覆盖层，以及浅深色和辅助功能退化样式。
- 独立的非模态设置窗口，复用主窗口的玻璃材质；内嵌分组、左侧标签与右侧真实控件，窄窗改为横向分类。

## Colors

### Primary

系统操作蓝（accent）用于主要按钮、列表选择、图标文件名选择、菜单动作悬停、输入光标与任务进度；深色使用 dark-accent。焦点环使用独立的半透明蓝。selection 是辅助选择背景，不替代活动文件的 accent 填充。

### Neutral

desktop 是暖色壁纸模式的后备色，不是文件内容色；RGB 模式使用用户选定或缓慢循环的预览背景色。六个循环停靠色与三通道滑杆的颜色只用于预览，不纳入产品品牌色。ink 接近暖黑，用于标题、正文与工具符号；secondary 用于导航符号、路径与元信息。surface / surface-soft 为实体表面，content 为半透明暖雾灰文件底，dark-content 为半透明中性炭灰；文件空白和活动标签共用该材质。content-header / dark-content-header 在浅深色与减少透明度状态下均为 transparent；表头共享下方内容层，不增加独立填充。reduced-content / dark-reduced-content 是减少透明度时内容层的实体底色，也为透明表头提供背景。window-fill 与 sidebar-tint 共同形成贯穿窗口边缘的磨砂侧栏；inspector-fill 为可选预览层。control-fill / control-selected 描述玻璃功能组与组内选择，menu-fill 保护密集文字浮层。dark- 前缀记录对应的深色值。

成功、危险、警告和标签圆点只表达状态。危险实心按钮固定使用 danger-fill / danger-hover 配白字，深色 danger 是危险文字色。reduced- 系列记录减少透明度的实体材质。前置颜色保留源 CSS 表达；sidecar 八级色带只供观察色相，不增加运行时令牌。

settings- 令牌记录设置的局部材质，dark-settings- 是对应深色值。设置覆盖已磨砂的主窗口，侧栏与内容面采用轻薄的补偿叠色，窗口模糊、投影与细亮边复用主窗口；以下局部值不替换主窗口 32% 的内容填充。分组仅在内容面上轻微叠色：

| 设置材质 | 浅色 | 深色 |
|---|---|---|
| settings-sidebar | rgba(255,252,245,.06) | rgba(34,34,30,.12) |
| settings-pane | rgba(241,240,237,.14) | rgba(35,35,32,.20) |
| settings-group | rgba(255,255,255,.06) | rgba(255,255,255,.025) |
| settings-nav-selection | rgba(255,255,255,.43) | #ffffff14 |
| settings-separator | rgba(35,35,32,.09) | rgba(255,255,255,.09) |
| settings-popup-hover | rgba(90,89,84,.09) | rgba(255,255,255,.075) |

设置分类选中底使用中性的 settings-nav-selection，文字使用 ink、字重 550，并保留轻投影与内亮边；分类符号使用 secondary 的单色 SF Symbols，外观分类采用 transparency 符号。开关开启底与外观缩略图选中环复用 accent，关闭开关使用 settings-switch-off。设置聚焦时，主窗口选择使用 settings-inactive-selection / ink 及其深色对应值，交通灯变为 #a9a8a3；点击回主窗口恢复活动表现。外观缩略图内的壁纸与微型窗口是局部示意图，其颜色不扩展为产品品牌色。

**The Selection Rule.** 产品控件中的操作蓝用于选择、焦点和明确主操作；工具符号近黑，导航符号使用中性灰。剪切和错误同时使用图标或文字。

## Typography

正文与控件使用系统 UI 字体栈，中文由 PingFang SC 等系统字体承接；路径使用 SFMono-Regular / Menlo。没有另设展示字体，窗口外的设计预览品牌标题不作为应用标题规则。

对话框采用 headline，当前位置采用 title，检查器采用 inspector-title。常规列表与导航使用 body（13 px）；图标文件名和按钮使用 file-name（12 px）；元信息、标签与菜单快捷键使用 label（11 px）。状态、存储信息与路径补全的辅助行也保持 11 px。当前位置标题字距为默认值，检查器轻微收紧；导航另有 −.1 px 字距。数值列使用等宽数字。

设置页标题使用 settings-title（16 px、600、1.25），分组标题使用 settings-section（12 px、600、1.4）。表单标签为 body，说明为 label；右侧下拉框使用 settings-popup（12 px / 20 px），快捷键为 12 px / 1.5 的系统字体与等宽数字。外观选项名为 11 px / 16 px，选中后字重 600；这些设置角色不改变主文件窗口的标题层级。

**The File Name Priority Rule.** 窗口变窄时先收起搜索和辅助列，再折叠侧栏；文件名保留可扫描的正文层级。

## Layout

| 区域 | 当前默认值 |
|---|---|
| 设计预览容器 | 最大宽 1380 px，左右内边距 40 px；页头高 68 px |
| 窗口 | 高 clamp(420px, calc(100svh − 185px), 780px) |
| 侧栏 | 通高、宽 194 px，无外边距；顶部 64 px 留给窗口控制；滚动区内边距 4px 11px 12px；条目高 30 px |
| 单层工具栏 | 高 64 px；左右内边距 13 / 18 px；功能组间距 9 px；组内按钮 31 × 29 px |
| 标签行 | 高 34 px，仅标签数 ≥ 2 时显示；单项最小宽 130 px、最大宽 240 px |
| 文件列表 | 列表滚动区内边距 0 0 18px；表头高 36 px，单元格顶部内边距 6 px；正文 13 px，行高 32 px，紧凑行高 29 px |
| 图标视图 | auto-fill，最小列宽 128 px，间距 18px 10px；图片 112 × 88 px |
| 底部路径与状态 | 高 38 px，左右内边距 13 px；路径显示 / 编辑区高 28 px；路径建议向上展开 |

## Elevation & Depth

共享窗口通过透色、模糊、细亮边和柔和投影近似磨砂材质。侧栏贯穿窗口边缘，仅加轻微填充；工具功能组用一致的玻璃填充与高光表现操作归属。文件内容以 32% 中性填充和背景模糊形成磨砂观感，表头始终透明且不设独立背景模糊，滚动行通过裁切保持在表头下方；不添加颗粒、内容渐变或内阴影。模糊作用于背后环境，文件图片与文字不施加 filter。阴影只用于窗口、控件归组、浮层和任务反馈，精确参数在 sidecar。

| 材质 | 处理 |
|---|---|
| 主窗口 | window-fill；blur(32px) saturate(1.25)；细内亮边与外投影 |
| 通高侧栏 | sidebar-tint；桌面使用窗口模糊；窄窗覆盖层使用 menu-fill 与 blur(20px) |
| 玻璃功能组 / 更多 / 搜索 | control-fill；统一内高光和轻投影，无独立背景模糊 |
| 检查器 | inspector-fill；桌面下无独立模糊 |
| 菜单 | menu-fill；blur(30px) saturate(.9) |
| 底部路径建议 | menu-fill；blur(24px)，向上展开 |
| 普通对话框 | menu-fill；blur(40px)；遮罩调暗但不模糊 |
| 独立设置窗口 | 外壳透明；复用主窗口的 blur(32px) saturate(1.25)、window-shadow 与 ::after 细亮边；侧栏 / 内容面采用 settings-sidebar / settings-pane 薄叠色，内嵌分组无独立模糊；无模态遮罩 |
| 文件内容 / 活动标签 | content / dark-content；32% 填充，blur(28px) |
| 吸顶表头 | thead / th 透明，无独立背景模糊，共享内容区的单层材质；滚动行裁切在表头下方 |
| 待操作条 | 中性半透明填充；blur(20px)，与任务条共享投影 |

**The Content Stability Rule.** 内容区和活动标签适量透出背景色，前景文字与媒体保持清晰；吸顶表头始终透明，共享内容层，通过裁切行内容防止滚动行进入表头区域。减少透明度时，内容与活动标签恢复实体底并移除背景模糊；表头仍透明，由实体内容层提供背景。菜单、路径建议与对话框继续使用稳固填充。

**The Functional Group Rule.** 关联操作共享玻璃功能组，组间以留白分隔；不要给每个普通图标分别套一个玻璃外壳。

**The Settings Material Rule.** 设置窗口复用主窗口的 32 px 模糊、1.25 饱和度、18 px 圆角、投影与细亮边。设置覆盖已磨砂的主窗口，因此侧栏和内容面使用轻薄的补偿叠色，保留环境透色；这些局部值不替换主窗口的 32% 内容材质。内嵌分组不加独立模糊；减少透明度时使用实体底，提高对比度时增强分组与下拉框边界。

手动减少透明度和 prefers-reduced-transparency 均将窗口、检查器、菜单与对话框改为前置 reduced- 材质并移除相关模糊，包括窄窗侧栏覆盖层。内容区与活动标签在两条入口下都使用 reduced-content / dark-reduced-content，并关闭背景模糊。表头保持 transparent，背景由实体内容层提供。窗口外的背景设置浮层也关闭模糊。侧栏与控件仍复合在实体窗口上。深色的两条入口使用相同的 dark-reduced-control-fill / dark-reduced-control-selected，避免浅色选中底与浅色符号冲突；浅色手动入口另将 control-fill / control-selected 改为 #ffffff30 / #ffffff9c，系统媒体查询保留浅色控件原有填充。待操作条为浅色 #f0efea / 深色 #383833，提示条为 #30302b；媒体窗口、控制、子组分别为 #242421 / #2a2a26 / #383833。浅色两条入口并非逐像素等同。

手动提高对比度将 secondary 提升为 ink，line 改为 #77777088，并增强视图组、路径、搜索、按钮及活动导航的边界。系统 prefers-contrast:more 使用浅色辅助文字 #373733 / 深色 #eeeee8，以及 #65655e88 / #cdcdc388 边线。保留可见焦点，但不以这些局部样式声称完成无障碍认证。

设置窗口的手动与系统减少透明度入口使用相同实体底：侧栏复用 reduced-window / dark-reduced-window（#e7e6e2 / #353530），内容面复用 reduced-content / dark-reduced-content（#f1f0ed / #232320），并关闭窗口级模糊；分组仍在实体内容面上轻微叠色。手动提高对比度与 prefers-contrast:more 均将设置分隔线改为 settings-high-contrast-separator（#77777088），分组增加 1 px 轮廓，下拉框增加 1 px 内边界。

原生版本应优先采用系统窗口、工具栏、菜单和导航材质。当前 CSS 是视觉近似，不能直接当作系统 Liquid Glass 的参数或行为规范。

## Shapes

窗口使用柔和圆角，按钮保持小圆角，玻璃功能组和搜索为胶囊，普通工具符号按钮为圆形。目录标签只有顶部圆角，当前标签与文件底色连接，无独立投影。侧栏贯穿窗口，不再是带外边距的浮动卡片。列表选择形成连续行；图标视图只给名称着选择色，并为缩略图加轻轮廓。

设置外壳复用主窗口的 18 px 圆角，内嵌分组为 12 px，分类条目与外观缩略图为 6 px，下拉框为 5 px；分类符号位于透明容器内。开关为 30 × 18 px、12 px 圆角，白色圆形滑块为 14 × 14 px，左上偏移 2 px，开启时水平移位 12 px。交通灯仍为 12 px 圆点，点击区域为 20 × 26 px。分组不使用主工具栏的胶囊轮廓。

SF Symbols 是 AppKit 导出的 72 px PNG 遮罩；当前素材有透明边距，因此使用 mask-size:128% 并居中补偿视觉尺寸。该补偿只适用于这组网页素材，不能作为原生系统图标缩放规范。基础工具容器 20 px，导航 19 px，路径 15 px；sidecar 的 SVG 遮罩样本包含同样补偿。文件类型 PNG 来自 NSWorkspace，原生应通过系统 API 取得。MyFolds 标记和壁纸几何为自绘 SVG；RGB 预览通过 luminosity 混合保留壁纸的明暗结构，该混合不作用于文件图片。素材归属见原型 assets/sources.json。

## Components

- **玻璃功能组：**剪切 / 复制 / 粘贴、视图 / 排序、双栏 / 预览分别成组。组内边距 3 px、间隙 1 px，组间距 9 px；组内按钮为 31 × 29 px 的圆形轮廓。视图与布局选中项使用 control-selected；更多操作为 35 px 圆形玻璃按钮。普通标题栏导航按钮保持无独立玻璃底。
- **文字按钮：**最小高 29 px；主按钮无阴影，次要与危险按钮保留轻投影。禁用透明度 .32。一般键盘焦点使用 3 px 的 focus 轮廓、偏移 2 px；悬停与按下反馈不改变位置。
- **搜索与路径：**搜索为 35 px 高胶囊，聚焦后显出稳定表面和 3 px 焦点环。完整路径移至底栏，常态透明，编辑态使用 surface 与 2 px 焦点环；路径建议向上浮出。内部输入不重复绘制焦点圈。显示可截断，复制与编辑保留完整路径。
- **侧栏与标签：**通高侧栏的活动项采用中性浅色填充、550 字重和轻高光；离线状态使用文字。标签可新增、切换和关闭；标签页保存路径、历史、选择、视图、搜索、预览、排序和滚动位置。一个标签时隐藏整行，多个标签时显示关闭与新增入口。
- **文件与预览：**列表为默认入口；空白区域与活动标签共用 content，thead 和单元格始终透明，共享内容区材质。tbody 使用 clip-path: inset(var(--list-scroll-offset, 0px) 0 0) 将文件行裁切在表头下方；原型捕获滚动事件，并在 render 和标签恢复滚动位置时同步该变量为非负 scrollTop。列表滚动区顶部及左右外层内边距均为零，表头和行背景贴齐两侧，行端部不设圆角；文字/图标保留单元格内边距。顶部留白移入表头：默认高 36 px / 顶部内边距 6 px，600 px 以下为 35 / 5 px，双栏为 30 / 0 px。列表 scroll-padding-top 分别为 36、35、30 px，让键盘滚入的文件避开表头。未选偶数行使用 #27252103 的极轻叠色，深色保留 #ffffff03。图标视图保持名称优先。未选文件时不弹出预览，显式开启检查器后显示文件夹信息；单选才显示相应内容。剪切只淡化缩略图与图标，并保留剪切标记。文件标签是只读圆点加文字，失焦选择转为中性灰。
- **菜单、任务与媒体：**密集文字菜单采用高不透明中性填充，条目最小高 30 px，悬停与聚焦使用 accent 配白字。普通对话框最大宽 500 px、最大高 90vh。任务进度条高 4 px，媒体最大宽 1050 px、舞台高 min(55vh, 550px)，没有预览入场动画。

- **设置窗口与分类：**偏好设置入口与 ⌘ , 打开同一扇非模态窗口；HTML 使用 dialog.show() 与 aria-modal=false，不加遮罩或焦点陷阱。再次打开会同步控件并聚焦当前分类，关闭后恢复入口焦点。红色关闭和黄色收起都关闭本次演示窗口，绿色按钮切换放大尺寸。分类采用 tablist / tab / tabpanel、aria-selected 与单一 tabIndex=0；方向键循环分类，Home / End 到首尾，窄窗同步 horizontal 方向。分类切换后面板回到顶部，面板自身可通过键盘聚焦与滚动。
- **内嵌设置行：**左标签、右控件，说明文字附在标签下方；组内相邻行仅画 1 px 内缩分隔线。下拉框使用真实 select，右对齐并预留上下箭头，常态透明、悬停使用 settings-popup-hover、按下使用 hover；宽度最小 65 px、最大 55%，520 px 以下最大 53%。开关使用有标签的 checkbox / role=switch，开启底复用 accent；滑块保留 0 1px 2px #0002 的轻阴影与 120 ms 过渡。辅助说明通过 aria-describedby 关联，聚焦时保留 3 px 焦点环。
- **外观单选：**真实 radio 提供浅色、深色、自动三项。“自动”监听系统外观变化，显式选浅色或深色后保持该选择。缩略图选中时显示 3 px accent 轮廓、偏移 2 px，标签加粗；键盘聚焦给整个选项 3 px focus 轮廓、偏移 5 px。悬停与按下的 brightness(1.04 / .94) 只用于小型示意缩略图。列表密度、减少透明度与提高对比度修改后即时作用于演示。
- **打开方式与快捷键：**JPEG、HEIC 与 MP4 的下拉选项共用主窗口 state.defaults，关闭再打开设置仍在当前演示内保留，并与“打开方式”菜单同步；不更改 Finder 系统默认应用。快捷键按浏览、文件操作、预览与设置分组，说明浏览器可能占用快捷键并提供同名界面入口。焦点位于设置内时阻止按键冒泡，Escape / ⌘ W 仅关闭设置，设置中的剪切、复制、粘贴等按键不会触发背后的文件操作；不持久化到下次加载。

- **预览背景控制（窗口外）：**页头“背景”按钮打开浏览器原生 Popover，提供 RGB 色彩 / 暖色壁纸切换。RGB 默认运行 36 秒六色循环，可暂停和继续；红、绿、蓝预设与 0–255 的 R/G/B 滑杆均可固定颜色，手动调色会暂停自动流动。Popover 宽 280 px、内边距 18 px、圆角 13 px，复用 menu-fill 和浮层投影。此入口只调整设计预览桌面，不增加文件管理产品功能。

按钮颜色过渡为 120 ms ease-out，预览遮罩与开关为 120 ms，进度宽度为 200 ms linear。产品控件的 prefers-reduced-motion 将动画与过渡缩至 .001 ms、次数设为 1，并关闭平滑滚动。预览背景单独使用 36s linear 循环；页面隐藏时暂停该动画及 250 ms 读数采样，重新可见后按播放状态恢复。系统减少动态效果时冻结背景并禁用播放按钮，仍可手动选择颜色或暖色模式。该动画不改变布局，不滤镜处理文件图片。sidecar 组件是自包含视觉样本，不提供真实文件操作。

## Do's and Don'ts

- **Do** 使用 MyFolds 名称、系统字体、SF Symbols 语义和熟悉的桌面操作层级。
- **Do** 保持完整路径常驻底部，预览按需开启，单标签时隐藏标签行。
- **Do** 按功能组织玻璃组，让内容适量透色并保持表头清晰，在不同 RGB 背景、浅深色和减少透明度状态下检查可读性。
- **Do** 让侧栏与文件区独立滚动，窄窗口仍保留侧栏入口及可见键盘焦点。
- **Do** 让设置即时生效并明确演示范围，使用真实选择控件、可见焦点和独立滚动。
- **Don't** 把网页材质、合成文件、浏览器尺寸或局部检查写成已实现的系统 Liquid Glass 与原生验证。
- **Don't** 把预览固定为单蓝色或全暖色，也不把 RGB 预览色扩展为产品品牌色；文件项目本身不另套玻璃卡片。
- **Don't** 为单个目录常驻额外的路径工具栏、空预览栏或假标签行。
- **Don't** 用 Unicode 字形或 emoji 代替 SF Symbols，也不把 Apple 系统图标当作 MyFolds 原创品牌素材。
- **Don't** 把设置内存状态写成持久偏好，或把 MyFolds 内的打开方式写成已更改 Finder 系统默认应用。
