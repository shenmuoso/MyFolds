# MyFolds 第一版功能清单

清单版本：v0.1 · 2026 年 11 月 20 日 · 首个原生可用版本的范围草案

依据：已确认的五项核心需求、当前 UI 设计方案 v0.6，以及设置与主窗口统一磨砂玻璃的最新设计。本文用于评审开发范围；清单中的功能均为计划，当前 HTML 原型不代表原生功能已实现。

## 1. 第一版目标与范围

第一版应能处理日常真实文件：浏览目录、直接剪切复制粘贴、编辑和复制完整路径、连续预览图片视频、记住打开应用，以及浏览和解压常用压缩包。

| 项目 | 本清单采用的范围 |
|---|---|
| 产品形态 | macOS 原生桌面文件管理器，名称 MyFolds |
| 界面基线 | 延续已确认的主窗口与设置设计；原生控件、简洁布局、透明磨砂、少分隔线 |
| 系统目标 | macOS 27 为重点适配与验收目标；最低兼容版本和处理器范围待确定 |
| 文件范围 | 用户授权的本地目录及常见外置磁盘；读写能力遵循实际权限和文件系统能力 |
| 首版必做 P0 | 下文功能清单全部属于 P0，是建议的首版交付范围 |
| 后续扩展 P1 | 单独列出，不作为首版默认承诺；升级为 P0 时同步调整范围 |
| 设置保存 | 原生应用需持久化偏好与类型规则；与仅保留内存状态的 HTML 演示区分 |
| 设计预览工具 | RGB 动态背景、演示场景与重置示例仅用于审阅设计，不计入原生产品功能 |

macOS 27 适配是产品目标；原生材质与控件行为需在实际 SDK 和系统中验证，网页的透明度与模糊数值仅作为视觉参考。

## 2. 首版必做功能 P0

### 2.1 文件浏览与目录导航

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| B01 | 真实目录访问 | 首次进入可访问的个人目录；打开受限位置时提供选择文件夹授权入口。授权失败或失效后保留位置并允许重新授权。无需访问所有文件即可开始使用 |
| B02 | 侧栏位置与收藏 | 提供常用目录、已连接磁盘和用户收藏；支持添加、移除与调整收藏顺序。磁盘或收藏目标不可用时可辨认，不跳转到无关目录 |
| B03 | 目录导航 | 支持进入目录、后退、前进、上一级；当前位置标题、路径与实际内容始终一致。应用包作为单项显示，不在普通浏览中自动展开内部文件 |
| B04 | 列表与图标视图 | 列表包含名称、修改日期、类型与大小；图标视图展示缩略图或类型图标。支持升降序、文件夹优先与显示隐藏文件；切换视图保留选择 |
| B05 | 选择与键盘浏览 | 支持单选、⌘ 多选、Shift 连续选择、全选、空白取消、方向键导航。对已选项目右键时保留多选，底部显示项目数与选中数量 |
| B06 | 当前目录搜索 | 按名称即时筛选当前目录，⌘F 聚焦搜索；保留关键词与清除入口。首版明确标注搜索范围，不递归扫描子目录 |
| B07 | 多标签 | 新建、关闭、切换标签；每个标签独立保留目录、历史、视图、筛选、选中和滚动位置。单标签时隐藏标签栏，⌘T / ⌘W 与窗口焦点规则一致 |
| B08 | 双栏浏览 | 两侧独立访问目录并显示各自路径；活动栏明确可辨，复制、粘贴与搜索作用于正确位置。开启双栏时收起检查器，避免三个狭窄内容区并排 |
| B09 | 刷新与外部变化 | 提供刷新入口；外部应用新增、删除、重命名文件后能更新列表。刷新尽量保留选择与滚动，原位置被移除时给出明确恢复入口 |

### 2.2 文件操作、剪贴板与任务反馈

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| F01 | 明确的剪切、复制、粘贴 | 工具栏、菜单栏、右键菜单提供一致入口；支持 ⌘X / ⌘C / ⌘V。粘贴前可辨认操作类型、项目数量与目标目录 |
| F02 | 待移动状态 | 剪切后源文件仍在原处，以标记和文字提示等待移动；粘贴成功后才完成移动。取消待移动不删除文件；新的剪贴板操作替换旧意图，重启不遗留待剪切状态 |
| F03 | 跨应用复制 | Finder → MyFolds、MyFolds → Finder 可复制真实文件引用。首版的 ⌘X 移动状态由 MyFolds 管理；外部应用粘贴不被误报为已移动 |
| F04 | 拖放文件 | 支持单栏内、双栏间和与 Finder 的拖放，遵循系统复制/移动语义；落点与操作类型有反馈。无效目标、移动到自身或自身子目录时拒绝执行 |
| F05 | 基础整理 | 新建文件夹、单项重命名、复制副本、移到废纸篓。重名、无权限等错误保留原内容；更改扩展名明确提示。首版不提供绕过废纸篓的永久删除入口 |
| F06 | 同名冲突 | 普通文件支持跳过、保留两份、替换、取消，并展示两份文件的名称、大小、修改时间。默认逐项决定，“应用到剩余冲突”必须由用户选择。文件夹同名首版提供跳过和保留两份，不自动合并或整目录替换 |
| F07 | 同盘与跨盘移动 | 同盘采用可靠移动行为；跨盘仅在某项复制完成并确认成功后删除对应源项。取消、断盘或复制失败时保留未完成项目的源文件，不将部分完成报成全部成功 |
| F08 | 进度、取消与失败处理 | 文件任务显示来源、目标、处理数量、已完成量和当前状态；可取消，并列出已完成、未完成及失败项。重试只针对需要的项目，重新检查冲突；长任务期间仍可浏览目录 |
| F09 | 有边界的撤销 | 新建、重命名、复制、移动、移到废纸篓在可恢复条件下支持 ⌘Z。外部文件变化、目标占用或磁盘离线时说明阻碍；替换操作只有旧目标确实可恢复时才显示可撤销。首版撤销范围为当前应用会话 |

补充规则：复制时尽量保留目标文件系统支持的修改时间、扩展属性等信息；不能保留的关键属性应在任务结果中说明。复制符号链接时保留链接本身，不递归跟随到其他目录。目标无法使用废纸篓时，不静默改为永久删除。应用被强制结束后的断点续传和自动回滚列为后续能力，首版至少能够识别未完成结果并给出清理或重试入口。

### 2.3 路径显示、复制与跳转

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| P01 | 常驻完整路径 | 底栏持续提供当前目录路径；过长时允许截断，但悬停、编辑与复制可获得完整值。双栏能分别辨认两侧位置 |
| P02 | 编辑与直接跳转 | 点击路径或 ⌘L 进入编辑并全选；Return 前往，Escape 取消。支持绝对路径、~、中文与空格；地址输入用于导航，不执行命令，也不隐式移动或重命名文件 |
| P03 | 文件定位与目录补全 | 输入目录路径直接进入；输入文件路径进入父目录并选中文件。提供可访问目录的补全与最近访问建议；选择建议后仍能核对完整位置 |
| P04 | 复制路径与错误恢复 | 当前目录一键复制；⌥⌘C 复制选中文件完整路径，多选按一行一个输出。不存在、无权限、磁盘离线分别提示，并保留原输入供修改 |

### 2.4 图片、视频与快速预览

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| M01 | 按需检查器 | 默认关闭；用户开启后随当前选择显示预览和真实元信息。无选择时显示目录信息，多选显示数量和汇总信息；取消选择不使整个窗口反复伸缩 |
| M02 | 独立快速预览 | 文件区 Space 打开，Escape 关闭并恢复文件焦点、选择与滚动。提供名称、当前序号、前后切换和外部应用入口；不为每个文件重复打开窗口 |
| M03 | 图片查看 | 支持适合窗口、100% 实际像素、缩放、平移与连续切换；读取实际尺寸和文件大小，正确处理图像方向与色彩信息。预览操作不改写原文件 |
| M04 | 视频播放 | 支持播放暂停、进度跳转、音量、时长和全屏。切换文件停止上一段播放；焦点在播放控件时，Space 优先执行播放/暂停，不被全局快捷键拦截 |
| M05 | 连续浏览范围 | 多选时在选中集合内切换；单选时沿当前目录、当前排序中的可预览媒体切换。筛选状态一致，退出预览后定位回当前文件 |
| M06 | 异步加载与失败回退 | 缩略图、解码和元信息读取不阻塞目录操作；快速切换时取消过时请求，不显示上一文件的内容。加载失败显示原因和选择应用入口，文件仍能正常整理 |

首版预览格式的具体目标见第 3 节。不能根据扩展名直接宣称视频可播放，也不能用示例缩略图代替真实格式支持。

### 2.5 打开方式与默认应用

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| O01 | 选择打开应用 | 右键菜单与检查器展示适合当前文件的已安装应用，支持选择其他应用。点击应用实际打开对应文件，失败时给出可采取的操作 |
| O02 | 仅本次打开 | 临时选择应用只影响当前操作，不改变后续默认，也不修改系统关联 |
| O03 | MyFolds 内默认 | 按文件类型保存规则，例如 JPEG 同时覆盖 .jpg 和 .jpeg。双击和“打开”优先使用 MyFolds 规则，无规则时使用系统默认；Space 始终保持预览语义 |
| O04 | 规则管理与系统范围 | 设置中查看、更改、清除类型规则，并在重启后保留。默认应用卸载或不可用时提供重新选择/系统默认回退。更改系统默认使用明确独立入口，引导系统关联流程；首版不承诺一键修改全系统默认应用 |

### 2.6 压缩包浏览、提取与创建

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| A01 | 压缩包目录浏览 | 对首版目标归档格式展示内部文件与目录，明确标注“压缩包 · 只读”；支持进入子目录和返回普通目录，路径能区分归档与真实文件夹 |
| A02 | 全部与选择性解压 | 无选择可全部解压，选择条目可只解压所选；执行前确认目标路径与冲突策略。解压后提供结果入口，原压缩包保持不变 |
| A03 | 包内复制 | 归档内复制并粘贴到普通目录等价于提取；首版不修改归档内部，不开放包内剪切、删除、重命名。单文件压缩流直接提取，不伪装成多层文件夹 |
| A04 | 创建 ZIP | 选中文件或目录后创建普通 ZIP，允许选择名称和目标，支持进度、取消与同名处理。首版创建不提供加密或高级参数面板 |
| A05 | 压缩错误与特殊包识别 | 能区分需要密码、缺少分卷、格式不支持与数据损坏；未支持的能力如实说明，不把加密包一律报为损坏。取消或失败后列出部分提取结果 |
| A06 | 解压范围与资源检查 | 写入严格限制在选定目标内，拦截绝对路径、越界路径及通过链接越界写入。检查可用空间和写入权限；遇到冲突按用户策略处理，不能静默覆盖 |

归档预览的第一版目标是目录浏览与提取；直接在压缩包内播放大视频、编辑文件后自动回写不属于首版范围。

### 2.7 原生界面、设置与持久化

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| U01 | 统一原生窗口 | 主窗口、设置、检查器和操作反馈遵循同一套磨砂玻璃、系统字体与符号规则；系统窗口控制、菜单、焦点和失焦行为符合 macOS 习惯 |
| U02 | 清晰且稳定的内容区 | 表头与文件区材质连续，行背景左右贴齐，文字保留必要内间距；背景可透色而文件名和媒体不模糊。滚动文件行不穿过表头，预览与任务反馈不遮挡最后一项 |
| U03 | 深浅色与辅助功能 | 浅色、深色、跟随系统；支持减少透明度、提高对比度、减少动态效果。控件有无障碍名称和可见焦点，状态不只靠颜色；用 VoiceOver 验证主要浏览与操作路径 |
| U04 | 原生键盘与菜单 | 常用操作在系统菜单栏可发现；快捷键遵循当前焦点，输入框内的剪切、复制、全选用于文字。设置、预览或弹出菜单处理按键时，不触发背后的文件操作 |
| S01 | 外观设置 | 延续独立设置窗口，支持外观、列表密度和辅助功能选项；更改即时生效。设置与主窗口共享视觉风格，关闭后回到合理焦点 |
| S02 | 打开方式设置 | 统一管理 O03/O04 的类型规则，设置与文件菜单状态一致；明确标示规则只作用于 MyFolds |
| S03 | 快捷键说明 | 按浏览、文件操作、预览分组显示实际可用快捷键；⌘, 打开设置，Escape / ⌘W 按当前窗口语义关闭。首版提供查看，不增加自定义键位编辑器 |
| S04 | 偏好与会话恢复 | 持久保存外观、密度、收藏、类型规则、窗口布局和标签目录。重启恢复可访问位置；权限过期、磁盘离线时逐项提示。待剪切状态与未完成写入任务不按普通界面状态自动重放 |

### 2.8 可靠性与基本性能

| 编号 | 功能 | 范围与验收要点 |
|---|---|---|
| R01 | 可辨认的异常状态 | 空目录、无结果、读取中、授权失败、只读、空间不足、磁盘断开、文件已不存在均有明确反馈与恢复入口，不用空白页面代替错误 |
| R02 | 大目录与长任务响应 | 用约 10,000 项的本地目录验证渐进加载、滚动、筛选和切换；列表不等待全部缩略图完成。复制、解压、预览期间窗口仍能响应导航和取消，具体时延指标在基准机器确定后锁定 |
| R03 | 文件操作结果可信 | 中文、空格、长路径、大小写冲突、空文件夹、符号链接与常见外置磁盘均纳入用例。已完成、部分完成、失败的报告与实际磁盘结果一致 |
| R04 | 原生验证 | 所有 P0 使用真实测试文件验收；确认操作前后数量、大小、内容与必要元信息，覆盖取消、断盘和无权限。玻璃、窗口焦点与辅助功能在实际 macOS 验证，HTML 截图不替代功能测试 |

## 3. 首版格式支持目标

以下是建议的开发与验收目标，尚未完成格式兼容测试。每个目标必须配套真实样本；表中“P0”不表示当前已支持。加密、分卷、特殊编码与损坏文件分别记录结果。

### 媒体

| 类型 | 首版 P0 目标 | 边界 |
|---|---|---|
| 普通图片 | JPEG / JPG、PNG、HEIC | 单张图像预览、缩放、方向和实际尺寸；特殊 HEIF 集合、Live Photo 等不随 HEIC 一并承诺 |
| 视频 | MP4 / MOV 中的 H.264 视频 + AAC 音频，以及对应无音轨样本 | 必须验证实际封装和编码组合、播放、拖动与音画同步；扩展名相同仍可能不支持 |
| 其他文件 | 提供系统支持的预览入口或外部应用入口 | 不宣称自带通用文档渲染器；不支持预览不影响复制、移动等操作 |
| 后续 P1 | GIF 动画、WebP、TIFF、RAW、HEVC、MKV、HDR、字幕与多音轨 | 按使用频率逐项增加，并说明硬件、系统或解码组件条件 |

### 压缩与归档

| 格式 | 浏览与提取目标 | 创建 | 首版边界 |
|---|---|---|---|
| ZIP | P0 | P0 | 普通、非加密、非分卷；文件名与目录结构需真实样本验证 |
| 7z | P0 | P1 | 非加密、非分卷；编码算法的实际支持范围随引擎样本矩阵声明 |
| RAR 4 / RAR 5 | P0 | 不计划 | 首版目标为非加密、非分卷；两代格式分别测试 |
| TAR | P0 | P1 | 目录结构、链接与属性处理需验证 |
| TAR.GZ / TAR.BZ2 / TAR.XZ | P0 | P1 | 包含归档层与压缩层，分别测试 |
| GZ / BZ2 / XZ | P0，提取单文件流 | P1 | 本身不当作多文件归档；输出名称冲突按普通文件处理 |
| 加密 ZIP / 7z / RAR | P1 | 不纳入首版创建 | 密码、算法、错误密码提示与密码处理单独验收 |
| RAR / 7z 等分卷 | P1 | 不纳入首版创建 | 首版至少识别不完整或不支持的组合并说明原因 |

## 4. 后续扩展 P1

| 编号 | 能力 | 推迟到后续版本的范围 |
|---|---|---|
| X01 | 批量重命名 | 模板、序号、正则、预览与批量撤销 |
| X02 | 更广的搜索 | 子目录递归、全盘索引、内容搜索、保存搜索条件 |
| X03 | 网络与云盘 | 专门的 SMB / SFTP 连接、云端占位文件下载、同步状态与离线策略；首版不承诺远程或云端语义完整支持 |
| X04 | 更广的媒体能力 | 第 3 节中的扩展格式、字幕、多音轨、RAW、HDR 和图片旋转等高级查看功能 |
| X05 | 高级压缩功能 | 加密、分卷、7z 创建、参数配置、包内预览及编辑回写 |
| X06 | 高级整理 | 文件夹合并、重复文件分析、批量标签编辑、自动整理规则 |
| X07 | 更强的任务恢复 | 暂停/继续、并发调度、跨重启断点续传、持久化撤销与崩溃后自动恢复 |
| X08 | 深度系统集成 | 默认文件管理器替换、Finder 扩展、自定义快捷键、系统级默认应用批量修改 |

## 5. 第一版验收场景

| 场景 | 完成标准 |
|---|---|
| 剪切并跨目录粘贴 | 工具栏与 ⌘X / ⌘V 均可完成；执行前看得到目标，取消待移动不影响源文件 |
| 与 Finder 交换文件 | 两个方向复制可用，文件内容与项目数量正确；外部粘贴不产生错误的移动成功提示 |
| 同名文件与文件夹 | 文件替换、跳过、保留两份范围明确；文件夹同名按首版规则处理，未选择的内容不被误改 |
| 跨盘移动时断开目标盘 | 未确认成功的源项仍在，部分完成状态可信，用户能定位并重试未完成项 |
| 直接输入路径 | 中文、空格、~、文件路径定位均可用；无效输入保留并提示原因 |
| 连续预览图片与视频 | 在当前排序/选择集合中切换；没有旧图闪回或后台旧视频继续播放；退出后回到原浏览位置 |
| 记住打开方式 | MyFolds 中设置的默认在重启后仍生效；系统默认保持原有范围，临时打开不污染类型规则 |
| 浏览和提取多格式压缩包 | P0 格式真实样本能列目录或识别单文件流，选择性提取结果正确，原包不变；异常与不支持组合有明确提示 |
| 大目录与后台任务 | 约 10,000 项目录和复制/解压并行时仍能浏览、切换与取消；记录基准设备及数据条件 |
| 窗口、设置与辅助功能 | 主窗口和设置材质一致；系统深浅色、减少透明度、键盘焦点及 VoiceOver 主路径可用 |

验收失败不能用原型中“看起来能操作”替代。出现缺陷时修复，或明确修改发布范围并记录原因。

## 6. 建议开发顺序

| 阶段 | 交付内容 | 完成后可验证 |
|---|---|---|
| 1 · 原生浏览基础 | 窗口、授权、目录列表、路径、选择、排序和基本设置 | 能浏览真实文件并准确到达指定位置 |
| 2 · 文件整理闭环 | 剪贴板、文件操作、冲突、任务、撤销、多标签与双栏 | 能可靠完成日常整理与跨目录移动 |
| 3 · 预览与打开 | 检查器、图片/视频、连续预览、默认应用及持久化 | 无需反复打开其他软件即可判断内容并选择合适应用 |
| 4 · 压缩与首版验收 | 格式引擎、浏览提取、ZIP 创建、异常恢复、性能与原生视觉验证 | 五项核心需求均有真实实现，达到本清单的首版验收范围 |

各阶段是内部交付顺序；首版的完整范围仍包含五项核心需求。此处不提供未经评估的工期承诺。

## 7. 仍需确定的范围选择

| 选择 | 当前草案采用的基线 | 确定后影响 |
|---|---|---|
| 使用与分发 | 先按可用的原生测试版本拆功能；个人使用、独立分发或 App Store 尚未决定 | 权限方案、签名发布、更新方式与发布验收 |
| 最低系统与硬件 | macOS 27 为验收目标，更早系统和 Intel 范围未锁定 | 材质兼容、系统接口与媒体测试矩阵 |
| 高频媒体与特殊压缩包 | 第 3 节为建议基础；MKV / HEVC、加密与分卷暂列 P1 | 若是日常刚需，应在开工前上调优先级并调整首版范围 |

以上未定项不妨碍评审功能清单；进入对应模块实现前应锁定，避免把建议误写成用户已确认的发布承诺。
