# 素材与来源

`mountain.jpg`、`coast.jpg`、`forest.jpg` 来自 Unsplash 公开样例；原始 URL 记录在 sources.json。作为设计中的演示文件，不代表用户数据。

`flower.mp4` 来自 MDN 的 CC0 示例视频；`flower.jpg` 为该视频的截帧。原型中 HEIC 名称使用 JPEG 样例展示 UI，并未解码 HEIC。

`symbols/*.png` 为安装的 macOS 系统 SF Symbols，通过 AppKit NSImage(systemSymbolName:) 导出的设计参考。`*-native.png` 为 NSWorkspace 返回的系统文件类型图标；外观可能随系统文件关联而变化。Apple 系统资源用于 macOS 界面设计参考，原生实现应使用对应系统 API，不把导出的 PNG 当作 MyFolds 原创品牌素材。

`myfolds.svg` 是本次设计绘制的 MyFolds 文件夹标记；`wallpaper.svg` 是暖香槟、象牙与浅陶土几何形状构成的演示桌面背景（原始暖色版本；v0.5 可通过 RGB 混合切换背景色）。二者不来自 Apple 官方壁纸或商标文件。

UI 截图来自此文件夹中的 HTML 原型。所有位图携带来源元数据，不使用 AI 生成图片冒充真实系统截图。Liquid Glass、窗口控制和文件操作均为网页设计模拟。
