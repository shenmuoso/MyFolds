# MyFolds 设计方案

macOS 原生风格 · 磨砂与 Liquid Glass 方向 · 产品设计 v0.6

直接打开 `index.html` 体验 UI，打开 `design.html` 阅读完整方案。若浏览器限制本地剪贴板或媒体访问，可在本文件夹执行 `python3 -m http.server 8766`，访问 `http://127.0.0.1:8766`。

这是设计原型，使用内存中的示例文件。网页中的玻璃是视觉模拟；真正的 macOS 27 系统材质、真实文件操作、应用启动与压缩解析尚未开发。

本版保留统一工具栏、通高磨砂侧栏、底部路径、按需预览和真实多标签。v0.5 增加窗口外的动态 RGB 背景预览，右上角“背景”可暂停、选红绿蓝或手动调整通道，也能切回暖色壁纸。中间内容与活动标签使用 32% 填充不透明度，透入背景色与柔和明暗；文字和媒体本身保持清晰。表头透明并共享文件区磨砂，滚动行只显示在列名下方，不再出现独立的实色横条。减少透明度时恢复实体材质。

本轮按反馈修正偏好设置的材质：去掉叠加过厚的白色填充，让侧栏、正文与分组透出背景色和模糊明暗；窗口边缘、投影、中性选中态与主窗口统一。13 张设置场景图已更新，增加绿色、蓝色和图片背景的材质图，交付包共 44 张 UI 截图。主文件窗口和核心流程沿用 v0.5 的场景记录。RGB 是设计预览控制，不是文件管理器的常驻功能。

列表边缘修正：表头、隔行底色和选中背景左右贴齐文件区；文字保留内间距，图标视图的布局保留。相关列表场景截图已同步。

偏好设置采用独立窗口：左侧“外观 / 打开方式 / 快捷键”，右侧使用外观缩略图、右对齐选择器和紧凑开关。设置即时生效，支持自动跟随系统；默认打开方式与文件菜单联动。更改只保留在本次演示内，关闭设置可按 Escape 或 ⌘W，打开可按 ⌘,。

可以体验：

- 常驻完整路径、编辑与跳转、复制路径。
- ⌘X / ⌘C / ⌘V，双栏移动、冲突处理、取消与撤销。
- 真实多标签：分别保留位置、视图、选中、查询和滚动。
- 图标 / 列表视图，搜索、排序、多选、新建与重命名。
- 图片快速预览、连续切换、本地 MP4 播放。
- 按类型选择打开应用，区分 MyFolds 默认与系统默认。
- 虚拟压缩包浏览及选择性提取。
- 深浅色、减少透明度、提高对比度及异常状态。

底部场景按钮会重置示例文件和当前任务。完整重置使用右下角“重置演示”。浏览器可能保留部分快捷键，可使用工具栏和右键菜单。

文件：

- `第一版功能清单.md`：原生首版范围草案 v0.1，包含 P0 功能、格式目标、验收场景和后续扩展；不表示功能已开发完成。
- `index.html`：交互原型。
- `design.html` / `设计方案.md`：完整产品与 UI 方案。
- `UI-main.jpg`：文稿两项且无选中的主窗口。
- `UI-settings.jpg` / `UI-settings-opening.jpg`：新版偏好设置与默认应用。
- `settings.css` / `settings.js`：独立设置窗口的样式与演示交互。
- `UI-photos-preview.jpg` / `UI-dark.jpg`：照片预览与深色主窗口。
- `UI-reduced-transparency.jpg`：减少透明度。
- 其他 `UI-*.jpg`：路径、移动、预览、打开方式、压缩包等界面。
- `DESIGN.md` / `design-tokens.json`：可复用的视觉规范与设计令牌。
- `验证说明.md`：交互和状态验证范围。
- `reference/原生设计对照.md`：Apple 实图依据及结构调整说明。
- `assets/sources.json` / `assets/README.md`：素材来源与设计参考说明。

照片、视频、路径、磁盘容量、应用列表和元信息均为演示内容。最低系统版本、发布方式、实际媒体与压缩格式支持范围留待原生开发前确认。产品名称已确定为 MyFolds。
