# 径 · macOS 文件管理器设计提案

打开 `index.html` 体验 UI 原型，打开 `design.html` 阅读带界面图的完整方案。

原型包含示例数据，操作只作用于内存中的演示文件。没有读取或修改真实文件，没有解码真实压缩包，也不会启动外部应用或修改系统默认关联。切换场景会重置示例状态。

建议先按下方场景依次体验：日常浏览 → 路径跳转 → 剪切与移动 → 媒体预览 → 打开方式 → 压缩包 → 异常状态。

直接用浏览器打开即可。浏览器可能拦截部分系统快捷键和剪贴板访问，此时可使用工具栏按钮；复制路径失败时会提供可手动复制的文本。

`设计方案.md` 是同一方案的可编辑文本版。`UI-*.png` 为各界面状态的静态图，`assets/` 提供离线预览所需的公开演示素材和来源记录。

本轮交付为设计方案与交互演示，没有创建原生 Swift 项目。产品名称「径」、视觉风格、支持格式和发布渠道均待后续确定。
