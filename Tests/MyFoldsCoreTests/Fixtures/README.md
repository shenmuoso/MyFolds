# RAR test fixtures

The RAR4 and RAR5 files are decoded from the libarchive 3.7.4 upstream test fixtures:

- https://github.com/libarchive/libarchive/blob/v3.7.4/libarchive/test/test_read_format_rar.rar.uu
- https://github.com/libarchive/libarchive/blob/v3.7.4/libarchive/test/test_read_format_rar5_stored.rar.uu

The encoded originals are retained alongside them. These files are test data only and are not shipped in MyFolds.app. Upstream source and license: https://github.com/libarchive/libarchive/blob/v3.7.4/COPYING
